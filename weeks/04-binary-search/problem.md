# 704. 二分查找

- 来源：LeetCode
- 链接：https://leetcode.cn/problems/binary-search/
- 题型：二分

## 描述

给一个**升序**整数数组 `nums`（元素互不相同）和一个目标值 `target`。如果 `target` 存在，返回它的下标，否则返回 `-1`。

要求时间复杂度是 O(log n)。

## 例子

```text
输入：nums = [-1, 0, 3, 5, 9, 12], target = 9
输出：4
解释：9 出现在下标 4
```

```text
输入：nums = [-1, 0, 3, 5, 9, 12], target = 2
输出：-1
解释：2 不存在
```

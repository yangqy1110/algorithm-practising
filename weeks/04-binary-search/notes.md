# 笔记 · 二分查找

## 思路

数组升序。用闭区间 `[i, j]`：答案如果存在，一定在这段里。每次看中间 `n = (i + j) // 2`。

- `nums[n] < target`：答案只可能在右边，`i = n + 1`
- `nums[n] > target`：答案只可能在左边，`j = n - 1`
- 相等：返回 `n`
- 区间缩空还没找到：返回 `-1`

循环用 `i <= j`，和闭区间、`±1` 收缩配套。

## 复杂度

- 时间：O(log n)，每次扔掉一半
- 空间：O(1)

## 踩坑

- 闭区间就要 `while i <= j`，排除中间必须 `n + 1` / `n - 1`，不要和半开区间混用
- 单元素、找不到，都要能自然退出
- 不要写成 `while i < j and nums[mid] != target` 再在循环外取值：`j` 变成 `-1` 时 Python 会访问 `nums[-1]`

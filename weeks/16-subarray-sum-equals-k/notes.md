# 复盘：怎么想到前缀和

最初按终点保存所有子数组和，空间 O(n²)，力扣报内存超限。连续区间和可写成两个前缀和的差，固定当前终点后，移项得到历史前缀和 = prefix_sum - k。

用字典存历史前缀和出现次数，直接查目标键；不再遍历字典。初始 {0: 1} 表示空前缀，先查询再记录当前值，更新次数必须 +1。

用户在引导后写出最终版本，保留其 if 判断风格。时间平均 O(n)，空间 O(n)。本地覆盖负数、零、重复前缀和，未核验力扣最终提交。

对照第53题：最大子数组和保存最小历史前缀和；本题保存每种前缀和出现次数。

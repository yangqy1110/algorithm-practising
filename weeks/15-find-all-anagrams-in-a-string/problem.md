# 438. 找到字符串中所有字母异位词

- 链接：https://leetcode.cn/problems/find-all-anagrams-in-a-string/
- 题型：滑动窗口、字符计数

给定由小写英文字母组成的字符串 s 和 p，找出 s 中所有与 p 互为字母异位词的连续子串，返回其起始下标。字母异位词要求字符种类和每种字符的数量相同，顺序可以不同。

- s = "cbaebabacd", p = "abc"，返回 [0, 6]。
- s = "abab", p = "ab"，返回 [0, 1, 2]。

先思考：候选子串的长度由什么决定？相邻两个候选子串之间，哪些字符发生了变化？

# 固定长度滑动窗口复盘

## 转换问题

字母异位词要求每种字符数量相同，顺序不限。候选子串长度必须等于 len(p)，于是只检查固定长度窗口。

## 复用信息

相邻窗口保留中间部分，只移出左端字符、移入右端字符。复用计数，每轮减一、加一，再与目标比较。

i 是新进入字符的下标；离开字符下标 i - size；新窗口起点 i - size + 1。

## 实现与疑问

用户开始用普通字典初始化，随后明确请求完整辅助实现，并偏好较简洁的 Counter 版本。已讲解 Counter 缺失键返回 0，可直接 += 1；Python 3.10+ 的 Counter 相等比较把缺失键按 0 处理。普通字典需要 get，比较前需删除零计数键；也可用 26 位列表手动计数。

这次在引导及辅助实现下完成整理，未确认独立重写或力扣提交通过。

## 复杂度

本题仅小写英文字母：时间 O(len(s) + len(p))，每次比较最多 26 种字符；不计结果列表的额外空间 O(26)。

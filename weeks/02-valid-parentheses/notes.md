# 笔记 · 有效的括号

## 思路

左括号进栈，右括号和栈顶配。配上就 `pop`，配不上或栈空就是非法。扫完栈必须空，否则有左括号没关上。

字典可以右→左（这个右括号要找谁），也可以左→右（这个左括号期待谁来关）。两种是镜像。

## 复杂度

- 时间：O(n)，每个字符进栈、出栈各最多一次。必须用 `pop()`，不要 `lis = lis[:-1]`（切片是 O(n)，最坏会变成 O(n²)）
- 空间：O(n)，最坏全是左括号

## 踩坑

- 交叉关掉非法：`([)]` 栈顶是 `[`，来的却是 `)`
- 栈空还来右括号：`")"` → `False`
- 扫完还有剩：`"("` → `False`
- 题解里的 `'?'` 哨兵：预先压一个不会被合法括号消掉的底，空栈和配不上走同一条 `pop` 判断；结束时 `len(stack) == 1` 才合法。短，但 `?` 必须同时在栈里和字典里

## 类似题要注意的点

括号 / 配对这类题，先问清四件事，再动手：

1. **栈里存什么**  
   存左括号本身、存下标，还是存「还缺的那个右括号」。要下标（最长有效括号、找匹配位置）就存下标，不要只存字符。

2. **什么时候弹，弹完怎么算**  
   配上就弹，是「消消乐」。有的题弹完还要看新栈顶，用下标算长度：`i - stack[-1]`。只判断合法时，弹掉就够了。

   `stack[-1]` 不是刚配上的那个左括号，而是这段合法括号左边、紧贴着的位置（上一处断开）。栈底常放 `-1` 当左边界。

   `"(()"` 下标 `0 1 2`：两个 `(` 进栈后，`)` 弹出 `1`，长度 `2 - 0 = 2`，最长是后面那段 `"()"`。  
   `"()()"`：第二次配上时栈底还是 `-1`，`3 - (-1) = 4`，两段连在一起。  
   `")()"`：开头的 `)` 变成新边界，后面 `"()"` 是 `2 - 0 = 2`。

   经典「最长有效括号」只有 `()`。多种括号时公式一样，弹出后还要核对 `s[弹出的下标]` 和当前右括号是否一对；对不上就把当前下标当新边界。

3. **两种失败不要漏**  
   - 右括号来了，栈空或类型不对  
   - 扫完栈里还有没关上的  
   题目如果改成「最少加几个 / 删几个才合法」，这两种失败分别对应「缺左」和「缺右」，要分开计数，不能只返回 `False`。

4. **嵌套 vs 交叉**  
   `{[]}` 合法、`([)]` 非法。栈只管最近一个未关的；交叉配不上栈顶，自然失败。不要用计数器（`left++` / `left--`）代替栈：只有一种括号时计数够用，多种括号必须记类型。

5. **字典方向和哨兵**  
   右→左或左→右都行，和栈里存的东西一致就行。哨兵能省空栈判断，但要想清楚它为什么消不掉。

6. **和单调栈分开**  
   下一类常见栈题（每日温度、下一个更大元素）栈里维护的是「还没找到答案的下标」，按大小弹，不是按括号配对。不要看到栈就套这题的模板。

# 笔记

## 递归思路

在引导下先思考左右子树都反转后当前层需要做什么，得到交换左右子树。空节点返回 None。自己补全了最初遗漏的 return node。

## 递归三要素

1. 定义函数负责什么、返回什么。本题反转子树并返回根节点。
2. 找到终止条件，并让每次调用接近它。本题空树直接返回 None。
3. 假设子问题已经解决，组合当前层的结果。本题交换左右递归结果并返回当前节点。

当问题能拆成规模更小、形式相同的子问题时，可以考虑递归。

## 复杂度

时间 O(n)，递归栈空间 O(h)，h 是树高。最坏 O(n)。

## 踩坑

当前写法会把递归返回值赋给左右孩子，漏写 return node 会导致父节点接收到 None，丢失连接。

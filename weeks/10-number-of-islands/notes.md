# 笔记

## 问题拆解

外层遍历发现未访问陆地时计数一次，调用 recur 标记整座岛，避免同岛重复计数。递归负责处理当前位置和上下左右相连的陆地，通过修改 grid 完成工作，返回 None。

## 踩坑

- 先判断越界，再访问网格。行数 len(grid)，列数 len(grid[0])。
- 网格元素为字符串 "0"、"1"。
- 上下左右每次只改变一个坐标，对角相邻不连通。
- 先标记，再递归，避免相邻陆地之间来回访问。
- 嵌套函数可直接使用外层 grid，修改元素无需 nonlocal。

## 复杂度及限制

时间 O(mn)，递归栈最坏 O(mn)。会修改输入。大岛屿可能超过 Python 递归深度限制，可用显式栈实现相同访问过程。

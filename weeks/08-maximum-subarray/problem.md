# 53. 最大子数组和

- 来源：力扣 53
- 链接：https://leetcode.cn/problems/maximum-subarray/
- 题型：动态规划

## 描述

给定一个非空整数数组，选择其中一段连续且至少包含一个元素的子数组，使这段元素的和最大。返回这个最大和。

## 例子

```text
[-2, 1, -3, 4, -1, 2, 1, -5, 4] → 6
选中的连续部分是 [4, -1, 2, 1]。

[1] → 1
[5, 4, -1, 7, 8] → 23
[-3, -1, -2] → -1
```

## 范围

数组长度为 1 到 100000，元素值为 -10000 到 10000。

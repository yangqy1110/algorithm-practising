# 笔记 · 爬楼梯

## 思路

最后一步要么跨 1 阶，要么跨 2 阶：

> 爬到 `n` 的方法数 = 爬到 `n-1` + 爬到 `n-2`

裸递归会重复算同一层，超时。改成滚动两个变量，每个阶只算一次。

```python
pre, cur = 0, 1
for _ in range(n):
    pre, cur = cur, pre + cur
return cur
```

`(0, 1)` 从地面滚 `n` 次。题解常见 `(1, 1)` 再滚 `n-1` 次，是同一串数、起点不同，复杂度一样。

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 踩坑

- 裸递归指数级，必须记忆化或自底向上
- `pre, cur = cur, pre + cur` 右边都是旧值，顺序安全
- 循环只跑次数，用 `_` 即可，不必用下标 `i`

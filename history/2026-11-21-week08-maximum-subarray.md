## 保存的解法

```python
max_sum = nums[0]
current_sum = 0
for num in nums:
    current_sum = max(current_sum + num, num)
    max_sum = max(max_sum, current_sum)
return max_sum
```

时间 O(n)，额外空间 O(1)。本地自测覆盖常见例子、单元素、全负数和零。此次未核验力扣提交结果。

## 自己的解法

```python
i, j = 0, len(nums) - 1
while i <= j:
    n = (i + j) // 2
    if nums[n] < target:
        i = n + 1
    elif nums[n] > target:
        j = n - 1
    else:
        return n
return -1
```

## 已经讲清楚，下周不用从零再讲

1. 有序才能二分：中间一比，扔掉一半，O(log n)。
2. 先定搜索区间。闭区间 `[i, j]` 配 `i <= j`，收缩用 `n + 1` / `n - 1`。
3. 半开 `[i, j)` 条件和收缩都要改，不要和闭区间混。
4. 找不到返回 `-1`；单元素不用特判。

## 和前几周的关系

哈希、栈、改链表指针都不需要。这题是「有序 + 每次排除一半」。递归反转链表仍未展开。

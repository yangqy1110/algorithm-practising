## 这次做了什么

- 做完 [70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/)。
- 先写出裸递归，超时；搞清是子问题被重复计算。
- 改成滚动 `pre, cur`，循环 `n` 次。
- 对比题解 `(1, 1)` 滚 `n-1` 次：少一轮常数，不是更快的算法。

下一周预告：合并两个有序链表。

## 自己的解法

```python
pre, cur = 0, 1
for _ in range(n):
    pre, cur = cur, pre + cur
return cur
```

## 已经讲清楚，下周不用从零再讲

1. 转移：`f(n) = f(n-1) + f(n-2)`。
2. 裸递归超时；滚动两变量即可 O(n) 时间、O(1) 空间。
3. `(0,1)` 滚 `n` 次，与 `(1,1)` 滚 `n-1` 次等价。
4. 和股票题一样：只留推进答案需要的状态。

## 自己的解法

存的是「还缺的数 → 下标」，不是更常见的「见过的数 → 下标」：

```python
dic[target - num] = i
if num in dic:
    return [i, dic[num]]
```

这两种是镜像：一个问「有没有人在等我」，一个问「我要的人来过没有」。返回顺序是 `[当前, 之前]`，题目允许。

## 对话里追问过的点

已经讲清楚，下周不用从零再讲：

1. **核心句**：反复在问「有没有配得上的数」时，用哈希把查找变成 O(1)，空间换时间。
2. **先查再放**：同一个位置不能和自己配对。`[3, 2, 4]`、`target = 6` 若先全部入表再查，`3` 会配到自己。
3. **只要判断存在就用 set**，仍然先查再放。反例：`[3, 1]`、`target = 6`，先放后查会误判。
4. **`Counter(nums)`**：扫一遍，得到「值 → 次数」。不记下标。`cnt[9]` 对不存在的键返回 `0`。
5. **什么时候上 Counter**：数有多少对，或补数等于自己时必须确认出现至少两次。自己配自己是 `n*(n-1)/2`，两类不同数是 `a*b`。
6. **按返回值选结构**：下标用 `dict`，有没有用 `set`，次数用 `Counter`。
7. **想新题的四步**：暴力在找什么 → 能否记下来 O(1) 查 → 先查还是先记 → 要下标、个数，还是只要有没有。

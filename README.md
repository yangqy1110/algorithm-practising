# 算法练习

每周一题，用 Python 写。目标不是刷很多题，而是把「读题 → 自己想 → 写代码 → 记笔记」养成习惯。

## 怎么练

1. 打开本周目录，先自己想 20–30 分钟，再写 `solution.py`。
2. 卡住了可以问我：**先要提示，不要直接看完整答案**。
3. 做完后把思路写进 `notes.md`（怎么想到的、复杂度、踩过的坑）。
4. 在本目录跑一遍自测：

```bash
python3 weeks/01-two-sum/solution.py
```

5. 做完一周就提交一次，推到 GitHub。

新的一周可以复制 `templates/`，改成 `weeks/02-题目名/`。
